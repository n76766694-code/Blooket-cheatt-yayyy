🛡 Anti-Ban (รันก่อนใช้สคริปต์อื่น) Safety

ลดความเสี่ยงการตรวจจับ (รันก่อนเสมอ)

💻 สำหรับ Windows (PC / Mac)

ใช้ DevTools ในเบราว์เซอร์ Chrome, Edge, หรือ Safari

1. เข้าเกม Blooket ที่ต้องการ (เช่น อยู่ใน Lobby หรือกำลังเล่น)
2. กดปุ่ม F12 (หรือคลิกขวา > Inspect) เพื่อเปิด Developer Tools
3. ไปที่แท็บ Console (อยู่ด้านบนของแผง DevTools)
4. ถ้า Chrome ขึ้นเตือนว่า "Warning: Don't paste code..." ให้พิมพ์คำว่า allow pasting ลงไปแล้วกด Enter
5. ก๊อปปี้โค้ดจากแท็บ Hacker Tools แล้วเอาไปวางใน Console กด Enter 1 ครั้ง

📱 สำหรับ Mobile (iOS / Android)

มือถือส่วนใหญ่ไม่มี Console ในตัว ต้องใช้วิธีใดวิธีหนึ่งด้านล่าง

วิธีที่ 1: ใช้แอป Kiwi Browser (Android)

1. โหลดแอป Kiwi Browser จาก Play Store
2. เปิดเกม Blooket ในแอปนี้
3. พิมพ์ chrome://inspect ในช่อง URL ด้านบน (หรือใช้เมนู ☰ > Developer tools)
4. จะมีหน้า Console เด้งขึ้นมา เอาโค้ดไปวางแล้วกด Enter

วิธีที่ 2: Bookmarklet (iOS Safari / Android Chrome)

1. ก๊อปปี้โค้ดจากแท็บ Hacker Tools
2. เพิ่ม Bookmark หน้าเว็บอะไรก็ได้ 1 อัน (เช่น หน้า Google)
3. ไปที่ Bookmark นั้นแล้วเลือก "แก้ไข" (Edit) เปลี่ยนชื่อเป็น Crash หรืออะไรก็ได้
4. ในช่อง URL ให้ลบของเดิมออก แล้วพิมพ์ javascript: ตามด้วยโค้ดที่ก๊อปมา (ต้องมีคำว่า javascript: นำหน้าติดกัน ไม่มีเว้นวรรค)
5. เซฟ Bookmark ไว้ เปิดเกม Blooket แล้วกด Bookmark นั้น 1 ครั้ง โค้ดจะรันทันที

⚠ ข้อควรระวัง

Crash / Kick / Freeze ใช้ได้เฉพาะตอนอยู่ในห้องเกม (ไม่ใช่หน้าแรก) และบางทีอาจทำให้เบราว์เซอร์ค้าง
Auto-Answer / Highlight ใช้ได้เฉพาะตอนที่เกมกำลังโชว์คำถาม (หน้าจอตอบคำถาม)
อย่ารันซ้ำ สคริปต์เดิมหลายรอบ เพราะจะทำให้เกิด Loop ซ้อนกันจนแอปค้าง
Anti-Ban ต้องรันก่อนเสมอ ถ้าจะใช้สคริปต์ตัวอื่น เพราะมันจะช่วยปิด Log ที่อาจถูกตรวจเจอ
